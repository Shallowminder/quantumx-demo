# QuantumX 移动端回归测试清单

这份清单用于每次移动端相关改动后的手动回归。重点关注账号弹层、底部导航、滚动、输入框、相关旧想法和数据页说明是否在手机上稳定可用。

## 1. 账号登录

- [ ] 手机点头像后账号弹层正常出现。
- [ ] 点邮箱输入框页面不自动放大。
- [ ] 键盘弹出后输入框仍可见。
- [ ] 输入邮箱并发送链接后提示正常。
- [ ] 弹层内滚动不意外关闭，点外部可关闭。

## 2. Today

- [ ] 手机首屏能快速记录。
- [ ] 保存想法后 toast 不遮挡底部导航。
- [ ] 相关旧想法卡片可打开。
- [ ] 反馈按钮可点击且选中态正常。

## 3. Search

- [ ] 搜索输入不触发页面异常缩放。
- [ ] 筛选和结果列表在窄屏可读。
- [ ] 相关旧想法卡片和反馈按钮正常。

## 4. Distill

- [ ] 选择主题、来源、输出类型可操作。
- [ ] 来源组成卡片不溢出。
- [ ] 草稿内容可编辑。
- [ ] 复制 Markdown 有成功或失败提示。
- [ ] 草稿筛选在手机上可用。

## 5. Data

- [ ] 下载备份按钮可点击。
- [ ] JSON 导入预览可读。
- [ ] 云端摘要和冲突提示不溢出。
- [ ] 隐私与删除说明卡片可读。

## 6. 通用

- [ ] 底部导航不遮挡主要按钮。
- [ ] 页面可滚动但不锁死。
- [ ] iOS Safari 和 Android Chrome 至少各测一次。

## 执行建议

每次改动 `MobileNav`、`AccountMenu`、`DataPage`、`TodayPage`、`SearchPage`、`DistillPage` 时，至少跑一遍相关部分。
